# 🌈 SupercaliSummarizer AI

**SupercaliSummarizer AI** is a free bilingual lecture-notes summarizer that detects, translates,  
and summarizes **Korean and English** text automatically using **Cloudflare Workers AI**.  
It runs entirely serverless — no API costs, no limits, and no user data stored.

---

## 🚀 Live Demo
👉 [supercalisummarizer-ai.pages.dev](https://supercalisummarizer-ai.pages.dev)

---

## 🧩 Features
- 🧠 **Automatic language detection** (Korean ↔ English)
- 🌍 **Translation** using `@cf/meta/m2m100-1.2b`
- ✍️ **Summarization** using `@cf/meta/llama-3.1-8b-instruct`
- 🪄 Smart formatting: paragraph + key-point bullets
- ⚡ Built with **Cloudflare Workers** and **Cloudflare Pages**
- 💸 100% free to run (no API keys needed)
